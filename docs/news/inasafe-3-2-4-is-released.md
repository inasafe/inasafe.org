# InaSAFE 3.2.4 is released!

We are pleased to announce that another release of InaSAFE is available. This is a bug fix release - please see our release notes for [details of what changed.](https://github.com/inasafe/inasafe/releases/tag/version-3_2_4) This release also introduced a new windows installer for installing the plugin in environments where there is no working internet connection.
