# InaSAFE 4.4 is released

[Version 4.4.0](https://github.com/inasafe/inasafe/releases/tag/version-4_4_0):

- Add Geonode uploader

- Add back Sentry configuration (need to be enabled in your settings)

- Set precision to 6 decimal for minimum needs.

- Add expressions for retrieving each section of the report ([#4986](https://github.com/inasafe/inasafe/pull/4986))

- Update to support InaSAFE run in headless mode

See more at [https://changelog.inasafe.org/en/inasafe/version/4.4.0/](https://changelog.inasafe.org/en/inasafe/version/4.4.0/)
