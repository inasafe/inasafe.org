# InaSAFE 3.2.6 is released!

This is a bug fix release to improve compatibility with keywords created in InaSAFE 3.2.x and those created in the upcoming 3.3.x releases.

* Add handler if found invalid xml file for version 3.2
* Add test data for layer with keyword version 3.3 and add unit test for it.

Windows users can install using the [executable installer here](https://github.com/inasafe/inasafe/releases/download/version-3_2_6/InaSAFE-3.2.6-plugin.exe). Users on other systems will find the upgrade available in the QGIS plugin manager shortly.
