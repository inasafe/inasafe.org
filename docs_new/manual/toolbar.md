
# Toolbar


Here the different icons (buttons) in the toolbar 
and the function of each are explained.


## Toggle InaSAFE Dock


![](../assets/user-docs/toolbar_toggle.png)


   *Toggle Dock*

This button shows and hides the InaSAFE dock.
After enabling the dock you are able to move it around your screen.
Dock it as a panel within the QGIS interface, or undock it so that
it floats as a separate window.

Find more information about the dock in the
toolbar_dock section.


## InaSAFE Keyword Editor


![](../assets/user-docs/toolbar_keyword.png)


   *Keyword Editor*

The **Keyword Editor** button opens the editor which is 
is used to edit the keywords needed for InaSAFE to create useful output. 
Keywords are explained in more detail in
keywords_system.


## InaSAFE Options


![](../assets/user-docs/toolbar_options.png)


   *Options*

This button opens the InaSAFE Options window which is described in
detail in toolbar_options.


## InaSAFE Impact Functions Browser


![](../assets/user-docs/toolbar_if_browser.png)


   *Impact Functions Browser*

This button opens the Impact Function Browser, which allows you to filter and 
browse impact functions that are available in InaSAFE.
More information can be found in impact_functions.


## InaSAFE Minimum Needs Tool


![](../assets/user-docs/toolbar_needs.png)


   *Minimum Needs Tool*

This tool calculates minimum needs for evacuated people.
For guidance on how to use this tool visit minimum_needs.


## InaSAFE Converter


![](../assets/user-docs/toolbar_converter.png)


   *Converter*

This tool converts an earthquake 'shakemap' that is in grid xml format
to a GeoTIFF file.
For more detailed information visit converter.


## InaSAFE Batch Runner


![](../assets/user-docs/toolbar_batch.png)


   *Batch Runner*

The Batch Runner is used to load saved scenarios (save_scenario) and
batch run them in one go.
Find more information about this tool in batch_runner.


## Save current scenario


![](../assets/user-docs/toolbar_scenario.png)


   *Save Current Scenario*

This is the tool to prepare/save scenarios for the
tb_batch_runner tool.
It lets you save the current visible scenario in QGIS to a `.txt` file.
Then this file can be opened as a scenario again in Batch runner and 
recalculated.
A more detailed description is available in batch_runner.


## InaSAFE OpenStreetMap Downloader


![](../assets/user-docs/toolbar_osm.png)


   *OpenStreetMap downloader*

This tool fetches building (structure) data from OpenStreetMap.
